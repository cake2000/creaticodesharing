## Introduction
&nbsp;
In this tutorial, you’ll learn how to build an AI program that translates between any two languages!
For example, you can say something in English, and your project will show and speak the translation in Spanish.

Here’s what we’re aiming for:

https://www.youtube.com/watch?v=SHumYtwjmOU

&nbsp;
&nbsp;
## Step 1 - Pick a Backdrop
&nbsp;
Please create a new project, and remove the dog sprite. [Select a backdrop](/topic/46/working-with-backdrops) for the stage, such as "Stars".

## Step 2 - Add the First Label
&nbsp;
Find the "Widgets" category in the palette, then [add a label widget](/topic/66/introduction-to-widgets-with-the-label-widget). Its text should be "Say something in English", and please try to make it cover the upper half of the stage:

ccimg||480||https://cdn.creaticode.com/scratch-gui-projects/forum/9b3cb4e0-9a91-44a5-9f6e-b7461a24e7c6.png
&nbsp;
As shown below, you can use the "Widget Position" tool to manually move and resize the label widget. You need to move the mouse slowly to keep dragging the handles. The position and size values in the block will be updated automatically.

## Step 6 - Translate the text
&nbsp;
Let's translate the words into Spanish!

First, create two variables:
* "**English words**" (to store what you said)
* "**Spanish words**" (to store the translation)
&nbsp;


ccimg3||800||https://cdn.creaticode.com/scratch-gui-projects/forum/1137207d-7bb1-44b7-b72b-895a584e615d.png


&nbsp;
**Step 6 Alternative: Use AI for Translation**
&nbsp;
Instead of using the "translate" block, we can also use the Large Language Model (LLM) block to do the translation:
&nbsp;
![0f316bff-2b31-4b87-8913-ad52421aa3eb-image.png](https://github.com/cake2000/creaticodesharing/blob/main/images/8ee32653-9119-4de4-bb3b-b581c82ba31d.png?raw=true) 
&nbsp;
Notes:
* In the prompt (request), we ask the AI to only return the translated text and nothing else. Without this requirement, the AI may return some additional words like "Sure, here is the translation:".
* The session type is "new chat", so that previous messages would not affect the current request.

## Additional Challenges
&nbsp;
There are many ways you can extend this project. Here are some ideas for your inspiration:

1. **Let the user pick two languages**
Add two dropdown menus so the user can pick any two languages to translate between.

2. **Translate in both directions**
Add buttons so both people can speak and get translations back and forth — one button for English → Spanish, another for Spanish → English.
